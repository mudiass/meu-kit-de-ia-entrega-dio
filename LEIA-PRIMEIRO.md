# Como usar esta entrega no VS Code

1. Extraia o ZIP.
2. Abra a pasta `meu-kit-de-ia-entrega` no VS Code.
3. Revise o `README.md` e os arquivos em `prompts/`, `delegacao/`, `execucao/` e `validacao/`.
4. Para usar no repositório-template da DIO, copie o conteúdo desta pasta para dentro da pasta local do seu repositório clonado, mantendo as pastas originais `01-prompts` a `05-delegacao-e-automacao`.
5. Confira o `README.md` antes do commit.
6. Adicione capturas de tela reais em `evidencias/`, conforme as instruções.
7. Faça commit e push para o seu GitHub.

Esta entrega contém a documentação do trabalho realizado; ela não substitui as pastas originais do kit da DIO. Mantenha-as no repositório que você criou a partir do template.
