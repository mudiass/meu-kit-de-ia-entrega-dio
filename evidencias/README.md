# Evidências da execução

Esta pasta foi reservada para as capturas de tela solicitadas no desafio original.

Os arquivos de texto em `../execucao/` registram o plano apresentado e o resultado produzido. Eles não são capturas de tela.

Para completar a exigência visual da DIO:
1. Abra a conversa em que o plano e o resultado foram produzidos.
2. Capture a parte da conversa que mostra o plano.
3. Capture a parte que mostra o cronograma final.
4. Salve as imagens nesta pasta com os nomes `plano-da-ia.png` e `resultado.png`.
5. Se necessário, atualize os links de imagem no README.

Não inclua dados pessoais, e-mails, informações privadas ou credenciais nas capturas.
